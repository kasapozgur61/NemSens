# NemSens
Flutter ile geliştirilen NemSens, giyilebilir biyosensörden (ESP32-C3) BLE ile gelen anlık ter iletkenlik verilerini alan mobil takip uygulamasıdır. Hareketli ortalama filtresiyle gürültüyü temizler, eşik değer analiziyle dehidratasyon riskini belirler ve JSON tabanlı yerel veritabanında (offline) seans geçmişini güvenle saklar.
